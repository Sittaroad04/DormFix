# 🏢 DormFix - ระบบแจ้งซ่อมสิ่งของชำรุดภายในหอพัก

ระบบเว็บแอปพลิเคชันสำหรับอำนวยความสะดวกให้ผู้พักอาศัยสามารถแจ้งซ่อมอุปกรณ์ชำรุดภายในห้องพัก และช่วยให้ผู้ดูแลระบบ (Admin) สามารถจัดการสถานะงานซ่อม พร้อมบันทึกประวัติ Timeline การดำเนินงานได้อย่างมีประสิทธิภาพ

---

## 🎨 จุดเด่นและฟีเจอร์การทำงาน

### 👤 สำหรับผู้พักอาศัย (Resident)
- **ระบบเข้าสู่ระบบ / ลงทะเบียน:** รองรับการลงทะเบียนด้วยชื่อ, ห้องพัก, อีเมล และรหัสผ่าน
- **Resident Dashboard:** สรุปข้อมูลผู้ใช้งานและทางลัดไปยังเมนูต่าง ๆ
- **แบบฟอร์มแจ้งซ่อม:** เลือกหมวดหมู่ (ไฟฟ้า, ประปา, แอร์, เฟอร์นิเจอร์), ระบุหัวข้อ, รายละเอียด และระดับความสำคัญ
- **รายการแจ้งซ่อม:** ตรวจสอบรายการแจ้งซ่อม พร้อมระบบกรองตามสถานะ (รอรับเรื่อง, กำลังดำเนินการ, ซ่อมเสร็จ, ปิดงาน)
- **ประวัติการแจ้งซ่อม (Timeline):** ติดตามความคืบหน้าการทำงานของช่างในรูปแบบ Vertical Timeline ทีละขั้นตอน

### 🛠️ สำหรับผู้ดูแลระบบ (Admin)
- **Admin Dashboard:** แผงควบคุมระบบสำหรับผู้ดูแลระบบ
- **รายการแจ้งซ่อมทั้งหมด:** การ์ดสถิติสรุปยอดงานแต่ละสถานะ พร้อมระบบกรองแบบละเอียด
- **จัดการสถานะงานซ่อม:** อัปเดตสถานะงานซ่อม (รอรับเรื่อง 🟡, กำลังดำเนินการ 🔵, ซ่อมเสร็จ 🟢, ปิดงาน ⚫) พร้อมระบุหมายเหตุการดำเนินงาน ซึ่งจะถูกบันทึกเข้าประวัติ Timeline อัตโนมัติ

---

## 💻 เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** React 19, React Router v7, Vite, Vanilla CSS (White / Clean / Minimal Design System)
- **Backend:** Node.js, Express.js
- **Database:** Microsoft Azure SQL Database / MSSQL (`mssql` driver)

---

## 🚀 วิธีการติดตั้งและรันโปรเจกต์

### 1. โคลนคลังข้อมูล (Clone Repository)
```bash
git clone https://github.com/Sittaroad04/DormFix.git
cd DormFix
```

### 2. ตั้งค่า Backend
```bash
cd backend
npm install
```
สร้างไฟล์ `.env` ตามตัวอย่างใน `.env.example`:
```env
PORT=5000
DATABASE_CONNECTION_STRING=your_azure_sql_connection_string
```
เริ่มรันเซิร์ฟเวอร์ Backend:
```bash
npm start
# หรือ node server.js
```

### 3. ตั้งค่า Frontend
เปิด Terminal ใหม่อีกหน้าต่าง:
```bash
cd frontend
npm install
npm run dev
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:5173`
